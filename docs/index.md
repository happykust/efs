# Документация efs

efs (Easy FSTEC SBOMs) готовит перечень заимствованных программных компонентов под требования ФСТЭК России и ГОСТ Р 56939-2024: генерирует SBOM, обогащает его ссылками на исходный код и ГОСТ-свойствами, проверяет заполненность и выгружает в CSV или ODT.

## Быстрый старт

```bash
uv tool install efs-sbom

efs scan                                    # сгенерировать SBOM (cdxgen или trivy)
efs config init bom.json                    # создать конфиг из SBOM
efs postprocess bom.json result.json \
  --app-name "МойПродукт" --app-version "1.0.0" --manufacturer "ООО МояКомпания"
efs check result.json                       # проверить схему и заполненность
efs export odt result.json perechen.odt     # выгрузить документ
```

## Формат данных

Перечень хранится в CycloneDX 1.6 (JSON) с расширениями ГОСТ, которые записываются в `properties` компонентов:

| Свойство | Значения | Что описывает |
|----------|----------|---------------|
| `GOST:attack_surface` | `yes`, `no`, `indirect` | Принадлежность компонента к поверхности атаки |
| `GOST:security_function` | `yes`, `no`, `indirect` | Принадлежность к компонентам, реализующим функции безопасности |
| `GOST:source_langs` | строка | Язык исходного кода. При нескольких языках — отдельное свойство на каждый |
| `GOST:provided_by` | строка | Название сертифицированного СЗИ, в составе которого поставляется компонент |

Подробнее о том, как эти свойства заполняются и проверяются — в [руководстве](fstec.md#гост-свойства).
